# Rules for agents and assistants

- Scientific and biographical content must remain separate from website code.
- Never modify scientific or biographical content while making a code or design change.
- Never modify website code when the requested change concerns content only, unless technically required.
- Never rewrite, shorten, summarize or alter scientific content unless explicitly requested by the user.
- Design changes must not modify Markdown or YAML scientific content.
- Never invent scientific references, DOI, project dates, project status, scientific roles, institutional responsibilities or URLs.
- If information is unknown, incomplete or uncertain, leave the field empty or mark it clearly as needing verification rather than inventing information.
- Preserve the language of existing content. In particular, Teaching & Outreach contains substantial French-language content intentionally.
- News data form a durable local archive independent of LinkedIn.
- The complete publication record is NOT maintained locally. Google Scholar is the reference for the complete publication list.
- Always run the appropriate build/tests before committing code changes.
- Prefer simple maintainable solutions over unnecessary framework complexity.
