# Community logo sources

The logo files are unmodified copies of assets served by the communities' official sites. Display dimensions are controlled in CSS; aspect ratios are preserved.

- `cordex-logo-positive.png`: https://cordex.org/wp-content/uploads/2025/02/CORDEX_RGB_logo_positive.png (official CORDEX logos page: https://cordex.org/publications/logos/)
- `clivar-logo-horizontal.png`: https://www.clivar.org/sites/default/files/field/image/CLIVAR_NewLogo_Horizontal.png (official announcement: https://www.clivar.org/news/introducing-new-clivar-logo)
- `euro-cordex-logo.jpg`: https://euro-cordex.net/imperia/md/images/microsites/eurocordex/fittosize__730_0_e00af355b954940cffd2d3eeea71802f_logo_eurocordex.jpg (official site: https://euro-cordex.net/)

Med-CORDEX reuses the existing `/images/v2/web/med-cordex-logo-simple.png` asset. JWG-ROCP displays the CLIVAR and CORDEX assets separately. Other entries retain an intentional text-only layout while no suitable identity file is available.
