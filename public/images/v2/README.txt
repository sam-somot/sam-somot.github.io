V2 visual assets

The source assets were supplied by Samuel Somot in the V2 visual-assets archive.
They remain preserved in that archive; optimized derivatives used by the site are
stored in web/ so the original multi-megabyte files are not sent to browsers.

FUTURA V2.1 provenance:
web/futura-logo-full-transparent.png was regenerated directly from the supplied
projects/futura/futura-logo-full-transparent.png (2423 x 1238), identified as the
preferred full transparent logo in README-ASSETS.txt. This is the stacked identity
(symbol above FUTURA), resized to 900 px wide with Sharp, without recolouring.

"Futura vertical logo.png". The source file remains unchanged in the archive.
